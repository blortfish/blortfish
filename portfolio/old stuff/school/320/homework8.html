Day 8: Unix Commands

Description: A list of unix commands and their definitions.

cd
- Typing just cd alone will move you into the home directory.
cd ..
- Used to go back one directory on the majority of all Unix shells. It is important that the space be between the cd and the ..
cd /
- This command will put you within the directory you specify with after the /
cd folder1
- This command will put you within the directory folder1

Permissions work as follows
  1. Owner (you)
  2. Group (a group of other users that you set up)
  3. World (anyone else browsing around on the file system)

  • 0 = no permissions whatsoever; this person cannot read, write, or execute the file
  • 1 = execute only
  • 2 = write only
  • 3 = write and execute (1+2)
  • 4 = read only
  • 5 = read and execute (4+1)
  • 6 = read and write (4+2)
  • 7 = read and write and execute (4+2+1)

chmod 644 file1
- Sets the access permission of file1 to 644
chmod 700 folder1
- Sets the access permission of folder1 to 700
chmod 755 folder1
- Sets the access permission of folder1 to 755
cp file1 file2
- Copies the contents of file1 into file2. If file2 does not exist, it is created; otherwise, file2 is overwritten with the contents of file1.
ls
- Lists the contents of a directory.
ls -l
- Shows you huge amounts of information (permissions, owners, size, and when last modified.)
ls -la
- Shows you huge amounts of information (permissions, owners, size, and when last modified.) for all files
man command_name
- To read a manual page for a Unix command use this syntax
mkdir folder1
- Makes a new directory, folder1
mv file1 file2
- If file2 does not exist, then file1 is renamed file2. If file2 exists, its contents are replaced with the contents of file1.
pwd
- Print working directory, is used to output the path of the current working directory
rm file1
- Deletes file1
rm proj?.html
- Delete all files named proj?.html where ? is any single character
rmdir folder1
- The "rmdir folder1" command removes a directory named "folder1" in the Unix shell's currently active directory. Note this command will fail on execution if the specified directory contains any files.
cal
- Displays a calendar
cal 10 2010
- Displays a calendar for [10] month and [2010] year.
say "I like Unix"
- Echoes I like Unix
cat file1
- The purpose of cat is to concatenate (or catenate) files.
telnet towel.blinkenlights.nl
- Plays Starwars in cmd
