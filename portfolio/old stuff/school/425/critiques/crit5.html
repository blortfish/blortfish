Critique V: Own Site

By: Daniel Flint

Due: April 13th

The overall design of my sketchbook is very simple and clean. The links are centered and the style sheet is used quite well. There are a total of three tones that contrast well against each other. However, The container that all the links are in could be a different color along with the links to the critiques in order to offer a contrast from the titles. The font styles are pretty plain and being that this is a small page, there could be use of more fancy font types.

Resizing the window is not an issue with this layout because it is centered. Similarity and proximity are used when grouping the links and the headings together. Some coloring is used to add contrast to the important parts of the page, but it could be improved. No matter where you put the window or what size it is, you will still be able to see and click the links. Also, when you zoom in there should not be any issues again because all of the links are centered. One note that should be taken into account is the use of some CSS3 style rules. This may be a problem for some browsers. However, it would only change the aesthetic value of the page but not the functionality.

One potentially irritating thing that was put on this page is the change of color, size, case, and font-weight when you hover over a link. When you do this, the container that holds the links increases in size. It is not a good practice because of window sizes. When you hover over a link, the page should stay static, on certain resolutions this will not be the case. The color background also is only highlights the current link you hover over, not the full line across which looks a little bit tacky.
