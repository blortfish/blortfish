Critique 6

By Daniel Flint

Site Critique 1

Link 1

This site's overall design is very simple. It is clean and does not include much. It is justified to the left side of the window which would make it accessible to those with lower resolution screens. Bertin's visual variables are overall used quite well. The shape is essentially a box with all information contained within that space. Size is also used well with headings being larger than the actual links beneath or the information pertaining to the heading. A picture is included in an appropriate place at the top of the site. The critique links are also within close proximity of one another. This would make it easy for the user to locate all links in sequential order. Coloring is the one variable that I am not very fond of on this site. CSS was not used to its potential, as it appears to be just a plain html document with no coloring. This is purely aesthetic however, and does not change the effectiveness of the layout. As I said before, resizing or zooming in the window should not change the look of this page very much at all because it was all placed in the left side of the browser window which is where most browsers will focus.

Site Critique 2

Link 2

The sketchbook done by John Ganz appears to be well thought out. Styling rules are applied well and the interface is very intuitive. Here again, Bertin's visual variables are key. It seems that most if not all aspects were attended to. The shape of the page is again a box model, however there are boxes that contrast from one another along with color. It brings a much more unified feel to the site and all of its parts. The size of navigation is done quite well. Having navigation located on the left of every page makes it very easy navigate between all pages. There is a relatively constant theme throughout all of his pages as well. There is almost always the navigation on the left, body text in the center, and any relevant images floating on the right side. In my opinion, coloring was done very well, there are only three tones, but they contrast well from one another and it allows the user to not be overwhelmed by colors. Upon resizing the window there are a few minute changes that could have been done. The text in the body runs all the way up against the pictures on the site if you pull the left to the right. This is not a major issue to the use of the site, but it would look better if padding was used or some other type of styling rule.
